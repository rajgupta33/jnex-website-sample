# JNEX Education Homepage

Responsive React and Vite homepage for JNEX Education, focused on medical admissions and NEET counselling.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Temporary images are documented in [IMAGE-ASSETS.md](./IMAGE-ASSETS.md). Replace the illustrative assets and confirm contact details, statistics, college information, and policy content before production launch.
